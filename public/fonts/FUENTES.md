# General Sans

Familia de Indian Type Foundry distribuida por Fontshare: https://www.fontshare.com/fonts/general-sans

Pesos 300, 400, 500, 600 y 700 descargados para servirlos localmente desde el CSS oficial:
https://api.fontshare.com/v2/css?f%5B%5D=general-sans@300,400,500,600,700&display=swap

Los archivos WOFF2 se conservan sin modificar. Licencia y condiciones de Fontshare: https://www.fontshare.com/licenses
